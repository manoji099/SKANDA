## 🚀 DEPLOYMENT IN 3 STEPS

### Step 1: Test Locally (5 minutes)
```powershell
cd d:\Skanda\Skanda_Home\website
python -m http.server 8000
# Open http://localhost:8000 in browser
```

### Step 2: Deploy to GitHub Pages (10 minutes)
```bash
cd d:\Skanda\Skanda_Home
git init
git add .
git commit -m "Skanda Engineering system"
git remote add origin https://github.com/YOUR_USERNAME/skanda-engineering.git
git push -u origin main
```

### Step 3: Enable GitHub Pages (2 minutes)
- Go to GitHub Settings → Pages
- Select: main branch / root folder
- Site available at: `https://YOUR_USERNAME.github.io/skanda-engineering`

**Total: 15-20 minutes to go live!**
